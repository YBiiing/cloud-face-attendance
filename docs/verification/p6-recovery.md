# P6：任务恢复与数据库竞争

恢复扫描采用每次最多 100 条的批处理，并以 15 秒发布租约限制重复投递；数据库已保存、队列尚未接收的任务会在租约到期后补投。执行租约丢失或到期时清除旧尝试标识；最多执行三次，worker 认领时也检查上限。数据库连接错误不猜测事务是否提交，由持久状态与后续租约恢复决定。

最终录入与签到事务遇到 MySQL 1205/1213 时，最多在新事务内重试三次；其他错误不盲目重试。现有原子写入、唯一约束和旧尝试校验保留。

新增隔离测试验证：投递失败后补投、短时间内不重复发布、执行租约恢复、执行次数上限、成功提交后重投不会二次执行，以及事务冲突的有限重试。首次相关测试 2 passed。更完整的操作与实际运行结果见 P6 本地运行报告。
