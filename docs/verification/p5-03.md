# P5-03 记录与班级统计

新增需登录的 `GET /api/records` 和 `GET /api/records/sessions`。普通用户的数据库查询强制限定本人，不接受请求参数覆盖身份；可选场次也限定为本人所属冻结名单。管理员选择场次后按冻结名单返回全班签到状态，全局视图仅列成功记录。响应使用 no-store。

统计在分页前计算应到、已到、暂未到与有效处理中任务数。场次结束且没有有效未完成任务后才标记 finalized。未知人脸只产生任务拒绝，不写入任何学生的缺勤记录。

隔离测试验证：无登录拒绝、普通用户隔离、管理员跨页总数一致、空页、无效场次、处理中转终态统计、退出后拒绝查询。另用 12 个线程竞争容量为 5 的 Redis 队列，验证只接收 5 个请求且释放后可补入 1 个；此测试验证配额原子性，不代表实际识别吞吐量。
