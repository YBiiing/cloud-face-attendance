# 本地分档负载验证

2026-09-30 在独立测试环境顺序运行 `python -m scripts.load_test`。原始记录见 [local-load.json](local-load.json)。各档为单轮短突发，未与回归测试同时运行。

最后一档完成无脸拒绝约 10.3 次/秒。跨档数据库时间统计：排队 P95 为 971.6ms，worker 处理 P95 为 79.6ms；处理时间包含模型调用和业务处理，不是单独的纯推理计时。百分位采用 nearest rank。端到端统计只包含已接收并完成的请求，429 单独报告。

这些结果验证了上传、队列、真实模型无脸检测、结果轮询和限流链路。它们不经过成功人脸编码与人员库检索，不能推导真人签到容量或识别准确率；未采集 CPU/内存峰值，也不是持续稳定性压测。后续有真实样本后再测多人新签到、重复签到、幂等命中及更大人员库，不据此调整生产参数。
