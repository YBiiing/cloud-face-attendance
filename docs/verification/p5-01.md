# P5-01 签到接收与幂等

实现公开 `POST /api/checkins`：只接收场次码、照片与随机幂等键；禁止客户端提交用户身份。完整校验照片后记录服务器接收时间，在场次锁内核对时间窗口，并通过 Redis 原子容量配额后持久保存任务。

历史请求在时间校验之前返回原任务，因此截止后重试不会新增任务。相同键不同内容冲突；任务查询需要凭证或管理员会话。队列满时返回 503，并删除本次临时照片，不创建悬空任务。

隔离 MySQL 集成测试覆盖：匿名提交、截止后重放、新请求截止拒绝、身份字段拒绝、不同内容冲突、无凭证查询拒绝、队列满无文件/任务残留。识别与记录写入由 P5-02 完成；本任务不声明签到成功。
